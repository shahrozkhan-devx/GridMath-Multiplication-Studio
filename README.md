A **simple and elegant Tables Generator App** built with **HTML, CSS, and JavaScript**.  
Users can enter a number to instantly generate its multiplication table in a clean, visually structured layout. Perfect for beginners learning loops, DOM manipulation, and real-time content updates.

🌐 **Live Demo:**  
👉 https://danish-devx.github.io/Tables-Generator-App/

---

## ✨ Features

- 🔢 Generate multiplication tables (1–10)  
- 🎨 Clean cream-themed UI with smooth buttons  
- 🧠 Beginner-friendly JavaScript logic  
- ⚡ Instant output updates  
- 🧹 Clear button to reset input and output  
- 📱 Responsive and easy to use  

---

## 🛠️ Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling & UI design  
- **JavaScript (ES6)** – Logic & DOM manipulation  

---

## 📂 Project Structure

Tables-Generator-App/ │ ├── index.html ├── style.css └── app.js

---

## 🚀 How It Works

1. User enters a number in the input field  
2. Clicks “Generate Table” button  
3. JavaScript creates the multiplication table dynamically  
4. Table displayed instantly below input  
5. Clear button resets input and output
